# Gosu, genomgången

Startpunkten för Gosu-genomgången i Programmering 2.

1. Tryck på **Fork** högst upp på den här sidan. Då får du din egen kopia.
2. Klona din kopia till datorn.
3. Kör `bundle install` i mappen. Det hämtar gosu, och första gången tar det en stund
   eftersom gosu byggs på din dator.
4. Följ genomgången på [kurssajten](https://ntijoh.github.io/programmering-2/uppgifter/).

## Vad som ligger här

* `media/img/` och `media/audio/` är bilderna och ljuden som genomgången använder.
* `Gemfile` säger att projektet behöver gosu. När du kör `bundle install` skrivs också en
  `Gemfile.lock` med de exakta versioner just din dator fick. Den checkar du in.
